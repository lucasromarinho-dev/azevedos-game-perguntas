# azevedos-game-perguntas

Banco de perguntas do Quest (Azevedo's Games).

- **10933 perguntas** em `perguntas.json` (banco v6: rodada 6 da expansão conferida, +974 sobre as 9959 do banco v5)
- **6 categorias**: Geografia, História, Ciências, Esportes, Entretenimento e Tecnologia
- **3 níveis**: fácil, médio e difícil
- Régua de dificuldade calibrada para **adultos competitivos**, com fatos conferidos em fonte
- Ano no enunciado é permitido em todas as categorias (obrigatório para fatos de 2020 em diante, que ficam no máximo em "medio")
- A mesma base é usada pelo app de TV (Android TV) e pelo jogo online **Loter Games**

Formato: array JSON em que cada item tem `categoria`, `dificuldade`, `pergunta`, `resposta` e `alternativas` (4 opções, incluindo a resposta).
